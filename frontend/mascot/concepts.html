Gatekeeper G · 概念草图 A / B / C

三个概念都是 「圆环身体 + 闸门臂 + 一只眼睛」 的字母 G，全部使用 --ink / --bg / --brand 三个 CSS 变量。每个概念在浅色与深背景下分别展示 24 / 48 / 96 px —— 重点检查 24px 时是否仍一眼是 G。
